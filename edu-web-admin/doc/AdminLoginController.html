2.1. 后台登录 登录之后返回token

URL: /login

Type: POST

Content-Type: application/json; charset=utf-8

Description: 后台登录只需要账号和密码 其他的信息不需要

Body-parameters:

Parameter Type Description Required Since

username

string

用户名

true

-

password

string

密码

true

-

Request-example:

curl -X POST -H 'Content-Type: application/json; charset=utf-8' -i /login --data '{
  "username": "randell.reinger",
  "password": "42axb4"
}'
