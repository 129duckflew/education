13. 后台管理:问题相关接口

13.1. 获取不同状态的问题

URL: /question/

Type: GET

Content-Type: application/x-www-form-urlencoded;charset=utf-8

Description: questionStatusCode含义: 0:被封禁 1:正常 2:待审核/审核中 3:审核不通过

Query-parameters:

Parameter Type Description Required Since

pageNum

int32

分页数(0为第一页)

false

-

pageSize

int32

分页大小

false

-

questionStatusCode

int32

问题状态码

true

-

Request-example:

curl -X GET -i /question/?pageNum=0&pageSize=5&questionStatusCode=452 --data '452'
