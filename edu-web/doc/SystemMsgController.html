14. 系统消息接口

14.1. 获取自己的所有未读消息总数

URL: /msg/not_read_count

Type: GET

Content-Type: application/x-www-form-urlencoded;charset=utf-8

Description: 获取自己的所有未读消息总数

Request-example:

curl -X GET -i /msg/not_read_count

Response-example:

{          "code": 200,          "msg": "ok",          "data": 0 //未读的消息总数        }

14.2. 根据消息类型获取类别下的所有消息

URL: /msg/type/{msgType}

Type: GET

Content-Type: application/x-www-form-urlencoded;charset=utf-8

Description: 0:系统广播消息 1:私聊 2:回答被点赞 3;回答被收藏 4:收到回答 5:收到问题邀请<br>6:问题被点赞 7:问题被封禁 8:回答被封禁 9:问题审核通过 10:问题审核不通过 11:教授收到评价<br>12: 回答审核通过 13:回答审核不通过

Path-parameters:

Parameter Type Description Required Since

msgType

int32
