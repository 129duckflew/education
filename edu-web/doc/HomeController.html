6.1. 前台用户登录

URL: /home/login

Type: POST

Content-Type: application/json; charset=utf-8

Description: Token的使用方法 TokenName是Token的参数名，TokenValue是Token的值 Token写在请求头中,有Token并且校验通过的认为已经登录

Body-parameters:

Parameter Type Description Required Since

loginType

int32

登录类型 1:邮箱登录,2:手机号登录,3:用户名密码登录,4:手机验证码登录;

true

-

username

string

用户名

false

如果是与用户名相关的登录 那就是必须的

password

string

密码

false

用到了密码就是必须的

email

string

邮箱

false

用到了邮箱就是必须的

telephoneNumber

string

手机号

false

用到了手机号就必须的

checkCode

string

邮箱/手机 验证码

false

具体是什么验证码根据登录类型的不同区分

Request-example:

curl -X POST -H 'Content-Type: application/json; charset=utf-8' -i /home/login --data '{
  "loginType": 462,
  "username": "darwin.weimann",
  "password": "l04tw3",
  "email": "eric.steuber@gmail.com",
  "telephoneNumber": "i1sqz1",
  "checkCode": "52390"
}'

Response-example:

{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "tokenName": "satoken",
    "tokenValue": "3728262f-a8a6-4b8d-98f2-7fb9225ac2a4",
    "isLogin": true,
    "loginId": "5",
    "loginType": "login",
    "tokenTimeout": 2592000,
    "sessionTimeout": 2592000,
    "tokenSessionTimeout": -2,
    "tokenActivityTimeout": -1,
    "loginDevice": "default-device",
    "tag": "nullq"
  }
}

string

password

string

密码

true

-

curl -X POST -H 'Content-Type: application/json; charset=utf-8' -i /home/register/text_msg_check --data '{
